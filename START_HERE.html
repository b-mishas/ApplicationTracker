Application tracker

A local tracker with an AI-assisted job search.

Before you start

  • Your assistant: Claude Pro or higher or ChatGPT plan with Codex.
  • Gmail: an account for job alerts.
  • Your CV: ready for building your search profile.
  • Time: Allow ~1.5 hours for setup.

1. Extract and open

Extract the entire ZIP into a folder you want to keep, such as Documents/Application tracker. Keep all extracted files together.

Double-click Application Tracker. The tracker opens in your browser.

First start on a Mac

macOS blocks downloaded files until you approve them once:

  1. Double-click Application Tracker. macOS says it could not verify the file. Click Done.
  2. Open System Settings → Privacy & Security and scroll down to Security. Next to the message about Application Tracker, click Open Anyway and confirm with your password or Touch ID.
  3. Double-click Application Tracker again and click Open.

macOS 14 or older: Control-click the file, choose Open, then Open again. Approve Restart tracker and Stop tracker the same way the first time you use them.

2. Set up the job search with your AI assistant

Open the Claude or ChatGPT desktop app and give it access to the whole extracted folder. Start a new chat and paste this prompt:

Setup instruction

Read agent/SETUP_PROMPT.md in this folder and guide me through setting up Application tracker. Treat this folder as ROOT. Follow the setup steps with me, ask for my background and preferences, and do not assume any personal information.

The assistant helps you:

  • Build your profile and choose search tracks and geography.
  • Make a list of potential employers.
  • Set up a search schedule.

Run the scheduled task once and check its results. You approve the profile and schedule, and sign in to services yourself.

The first test run takes 30 minutes or more. On day one Gmail may have no job alerts yet; that is normal.

If it cannot read the setup file, open agent/SETUP_PROMPT.md and paste the text between the COPY markers.

3. Daily routine

  • Double-click Application Tracker whenever you want to see the tracker. You can bookmark the page; if the bookmark does not open after restarting your computer, double-click Application Tracker again. Closing the browser tab is fine.
  • Keep the computer awake and the AI app running for scheduled searches.

Back up this folder. After setup it holds your private data: do not share it, and do not replace it with a new download. Your assistant never applies, sends messages or changes your CV.

Change your search later

Return to your setup chat, which already has access to the Application tracker folder, and paste:

Change your search

Read agent/CUSTOMIZE.md, then help me change my search.

If something goes wrong

If Windows asks whether to run the file, allow it.

If macOS blocks a file, approve it as described in First start on a Mac.

If the tracker does not respond, double-click Restart tracker. To close it completely, double-click Stop tracker.

For startup problems, copy this to your assistant:

Startup help

Read data/logs/server.log in this folder and help me fix the tracker startup problem.

To report a problem with setup or the daily search, copy this to your assistant.

Problem report

Run node app/diagnostics.mjs in this folder and tell me where the file is saved.

Your records stay on this computer. Guides for Claude, Codex and Gmail alerts are in the guides folder.
