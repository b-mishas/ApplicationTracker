Application tracker

A local tracker with an AI-assisted job search.

Before you start

  • Your assistant: Claude Pro or higher or ChatGPT plan with Codex.
  • Gmail: an account for job alerts.
  • Your CV: ready for building your search profile.
  • Time: Allow ~1.5 hours for setup.

1. Extract and open

Extract the entire ZIP into a folder you want to keep, such as Documents/Application tracker. Then start using:

  • Windows: Start (Windows).cmd file
  • Mac: Start (Mac).command file

Your browser opens an empty tracker. Keep all the extracted files together. The Start file reopens the tracker if it is already running. Use the Restart file after an update, or the Stop file to shut down the background server. Use the files matching your system.

2. Set up job search with LLM assistant

Open Claude or Codex in a desktop environment that can work with local folders. Give it access to the whole extracted folder. Start a new chat and paste this prompt:

Setup instruction
Read agent/SETUP_PROMPT.md in this folder and guide me through setting up Application tracker. Treat this folder as ROOT. Follow the setup steps with me, ask for my background and preferences, and do not assume any personal information.

The assistant helps you:

  • Build your profile and choose search tracks and geography.
  • Make a list of potential employers.
  • Set up a search schedule.

    • Run the scheduled task once and check its results.

You approve the profile and schedule, and sign in to services yourself.

  • Test run: allow 30 minutes or more.
  • New alerts: an empty Gmail result is expected on day one.
  • Check: review completed and failed work in the summary’s Coverage line; confirm new positions appear in the tracker.

If it cannot read the setup file, open agent/SETUP_PROMPT.md and paste the text between the COPY markers.

3. Daily routine

  • Open the Start file once, then bookmark the tracker’s address. It normally uses http://127.0.0.1:8765 and keeps the same address after restarting. Closing the browser leaves the tracker running.
  • In Settings, optionally enable Start server at login and save. From your next login, the tracker starts quietly; open your bookmark when needed. Otherwise, open the Start file once after logging in.
  • Keep the computer awake and the AI app running for local scheduled searches.
  • You can export your applications as Excel or PDF using the corresponding buttons at the top right.

Back up this whole folder. Once personalized, it contains private information; do not share it or replace it with a blank download. Your assistant's routine never applies, sends messages or changes your CV.

Change your search later

Return to your setup chat, which already has access to the Application tracker folder, and paste:

Change your search
Read agent/CUSTOMIZE.md, then help me change my search.

  • Profile: search tracks and geography.
  • Settings → Excel language (for export): language for both Excel and PDF.
  • Settings → Name: name in exported report titles.
  • Settings → Start server at login: starts this tracker on your computer, independently of the assistant’s search schedule. Disable and save before moving or deleting the folder; enable it again after moving.

If something is blocked

Downloaded starters or runtimes may need operating-system approval. Review the package source and follow the system's displayed instructions; do not disable protections.

If the local address is already used by another program, the tracker reports the conflict instead of changing its address. Your assistant can help choose another fixed port; bookmark the new address afterwards.

For startup problems, copy this to your assistant:

Startup help
Read data/logs/server.log in this folder and help me fix the tracker startup problem.

The tracker stores records locally. Connected AI services process material you give them access to. Platform-specific instructions are in guides/.
