Application tracker

A local tracker with an AI-assisted job search. Start here; no programming knowledge is needed.

1. Extract and open

Extract the entire ZIP into a folder you want to keep, such as Documents/Application tracker. Then double-click:

  • Windows: Start Windows.cmd
  • Mac: Start macOS.command

Your browser opens an empty tracker. No Node.js, Python or package installation is needed. Keep all the extracted files together. The matching Stop file stops the background server.

2. Set up your search with your assistant

Open Claude or Codex in a desktop environment that can work with local folders. Give it access to the whole extracted folder. Copy this into a new conversation:

Setup instruction
Read agent/SETUP_PROMPT.md in this folder and guide me through setting up Application tracker. Treat this folder as ROOT. Follow the setup steps with me, ask for my background and preferences, and do not assume any personal information.

Have your CV ready. The assistant interviews you, helps choose tracks and geography, sets your Excel export language, fills your employer list and helps set up alerts and a schedule. You approve the profile and schedule. You sign in to services yourself.

If it cannot read the setup file, open agent/SETUP_PROMPT.md and paste the text between the COPY markers.

3. Test before scheduling

Copy this to your assistant:

Test instruction
Run the installation check and one test search with me.

Check the summary and any new positions in the browser. Enable unattended searches only after setup and intended connectors work.

Every day

  • Open the Start file to reopen the tracker. Use the star, dismiss icon and status editor to track decisions.
  • Keep the computer awake and the AI app running for local scheduled searches. Close the employer workbook in Excel before a search.
  • Use Export applications for Excel. Applied positions need an actual application date.

Back up this whole folder. Once personalized it contains private information; do not share it or replace it with a blank download. Your assistant's routine never applies, sends messages or changes your CV.

Change your search later

Give your assistant access to this folder and copy this into the conversation:

Change your search
Read agent/CUSTOMIZE.md, then help me change my search.

Search tracks and geography belong in your profile; the agent assigns them to each position. The tracker’s Settings screen controls Excel export language.

If something is blocked

Downloaded starters or runtimes may need operating-system approval. Review the package source and follow the system's displayed instructions; do not disable protections. Real macOS and Windows ARM64 acceptance checks are still pending.

For startup problems, copy this to your assistant:

Startup help
Read data/logs/server.log in this folder and help me fix the tracker startup problem.

The tracker stores records locally. The search needs an appropriate AI account/app, internet access and your approved connectors. Connected AI services process material you give them access to. Platform-specific instructions are in guides/.
